WhatsApp Assistant Pro+ 隐私政策

最后更新日期：2026年10月12日

感谢您使用 WhatsApp Assistant Pro+。我们非常重视您的隐私和个人信息安全。本隐私政策旨在向您说明我们如何收集、使用和保护您的信息。

1. 信息收集

我们处理的信息取决于您启用的功能，可能包括：

  • 您主动发起翻译/分析时的文本内容
  • 您主动发起语音转写时的音频内容（仅在使用 STT 功能时）
  • 您配置的 API 密钥、接口地址、模型与功能开关
  • 与联系人相关的本地偏好（如输入框目标语言、快捷翻译发送开关、天气国家纠正）
  • 开启「记住已翻译的消息」时，已翻译消息的译文及其原文指纹（用于切换会话、刷新页面后直接复用译文）
  • 为识别联系人号码而在本地缓存的聊天标识与电话号码映射；对方在 WhatsApp 中隐藏了手机号时，改为记录 WhatsApp 为该联系人分配的匿名标识（LID），仅用于在本机区分联系人、记住对应的语言与快捷翻译偏好

2. 信息使用

上述信息仅用于：

  • 提供翻译、AI 分析、语音转写、天气信息与输入框快捷翻译等您主动使用的功能
  • 在本地记住语言/快捷发送等偏好，避免重复配置
  • 排查功能故障与改进稳定性

3. 存储位置与保留

我们采取以下方式处理数据：

  • API 密钥与多数功能配置保存在浏览器 chrome.storage.sync（随 Chrome 账号同步）
  • 语言偏好、快捷翻译偏好、联系人号码缓存、天气纠正等保存在浏览器 chrome.storage.local（本机）。这些偏好以联系人的电话号码、群组标识或匿名标识（LID）区分
  • 联系人身份识别在您已打开的 WhatsApp 网页内、于本机完成：扩展读取当前聊天在页面中已有的标识信息，不会为此额外向 WhatsApp 或任何第三方发起网络请求，也不会把这些标识发送给我们
  • 开启「记住已翻译的消息」后，消息译文与原文指纹（不含聊天原文）保存在浏览器 chrome.storage.local（本机），最多 1200 条、且不超过约 4MB，超出部分会自动淘汰最旧的记录；超过 30 天的记录自动过期删除；关闭该开关会立即删除已保存的译文缓存
  • AI 翻译的「思考过程」不会写入磁盘：它可能逐字复述原文消息，因此仅保留在当前页面内存中，关闭或刷新页面即消失
  • 发送给第三方 Provider 的翻译/分析/转写内容仅在请求期间处理，扩展不会在云端永久保存聊天正文
  • 您可在设置页的“隐私保护”中查看、导出、导入或清空本机记录
  • 主动配置 WebDAV 后，所选设置与联系人偏好会加密备份到您指定的服务器（推荐 HTTPS；若选择 HTTP，WebDAV 凭据会以明文传输，需在表单中确认风险）。API 密钥与译文缓存需要单独勾选。远端备份不包含聊天原文、AI 思考过程、运行日志及 WebDAV 凭据
  • 若改用 Google 云端硬盘备份（该功能需在构建时配置 Google 授权；未配置的版本中仍可看到此选项，但保存连接时会提示「本构建尚未配置 Google OAuth 客户端 ID」，不会向 Google 发出任何网络请求），同样的加密备份文件会写入您自己的云端硬盘。扩展仅申请 drive.file 权限，只能读写它自己在您指定文件夹中建立的备份文件，无法访问您云端硬盘中的其他内容；备份在上传前已在本机加密，Google 与我们都无法读取其中的明文。备份文件归您所有，可随时在云端硬盘中查看或删除。我们不设任何服务器，备份数据不会经由我们传输或保存
  • Google 账号的访问令牌由 Chrome 自身托管（chrome.identity），扩展不保存刷新令牌，也不会把令牌发送给 WhatsApp 页面或任何第三方。您可随时在 Google 账号的第三方应用页面撤销授权
  • WebDAV 凭据及不可导出的加密派生凭据保存在扩展自身的 IndexedDB 中，不发送给 WhatsApp 页面。记住解锁能力不代表能够抵御本机扩展数据被读取
  • 恢复前在扩展本地保留最近 3 份加密恢复点。恢复或导出缓存时继续过滤过期译文；远端的既有加密备份及本地恢复点不会因关闭某类别或清空业务记录而立即删除，您可自行删除远端备份文件；卸载扩展会移除本机恢复点

4. 浏览器权限用途

  • storage：在 chrome.storage 中保存功能配置与偏好
  • activeTab / scripting：在当前 WhatsApp 标签页内提供翻译与辅助功能；其中 scripting 还用于向 WhatsApp 页面注入随扩展打包的开源组件 WPPConnect/WA-JS，在本机识别当前聊天的联系人身份（已关闭该组件的上游统计上报）
  • identity（可选权限）：仅在您选择 Google 云端硬盘备份并点击保存连接时才会申请，用于获取访问您云端硬盘的授权令牌。不使用该备份方式则不会申请，也不会读取您的 Google 账号身份信息
  • https://www.googleapis.com/*（可选主机权限）：与 identity 同时、且仅在您选择 Google 云端硬盘备份时申请，只用于读写扩展自己建立的备份文件
  • alarms：仅在您启用「备份与同步」并连接备份服务后，按您本机的数据变化安排加密备份的定时上传（设置变化合并 30 秒、译文缓存合并 5 分钟），以及在连接失败时按 1/5/15 分钟的间隔自动重试。闹钟内容不包含任何用户数据，只是触发时间点；功能关闭时闹钟即被清除

5. 第三方服务

根据您的配置，数据可能发送到您启用的 Provider，例如：

  • 翻译：DeepL / DeepLX、Google 翻译、微软 Edge 翻译、OpenAI 兼容接口、DeepSeek、通义、火山等
  • AI 分析：您配置的 AI Provider（如 OpenAI 兼容接口、DeepSeek 等）
  • 语音转写：您配置的 STT Provider
  • 天气：第三方天气数据源（如 wttr）

这些服务的使用受其各自隐私政策约束。未启用的 Provider 不会接收对应数据。

6. 用户权利与控制

作为用户，您可以：

  • 随时修改或删除已保存的 API 密钥与配置
  • 按功能开关禁用翻译、AI 分析、语音转写、天气与快捷发送
  • 在隐私保护页清空本地偏好与缓存记录
  • 要求获取关于数据使用情况的说明

重要提示：

本扩展程序：

  • 不会在未启用对应功能时主动外发您的聊天内容
  • 在您主动使用 AI 分析时，会把您选中的聊天文本发送到您配置的 AI Provider
  • 在您主动使用语音转写时，会把音频发送到您配置的 STT Provider
  • 不会把 API 密钥上传到我们的服务器；密钥保存在浏览器存储中
  • 不会在未经您操作/配置的情况下与无关第三方共享数据

7. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的版本将在本页面发布，并在扩展程序中通知用户。继续使用我们的服务即表示您同意新的隐私政策。
